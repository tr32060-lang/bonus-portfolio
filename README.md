# E-Portfolio | แฟ้มสะสมผลงานออนไลน์

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) จัดทำขึ้นเพื่อรวบรวมข้อมูลส่วนตัว ผลงาน และกิจกรรมต่าง ๆ ของผู้จัดทำ เพื่อแสดงทักษะ ความสามารถ และประสบการณ์ในการเรียนรู้

## 👩‍🎓 ข้อมูลผู้จัดทำ
- **ชื่อ:** พรปวีณ์ เนืองสุวรรณ
- **ชั้น:** ม.6/13
- **เลขที่:** 12
- **โรงเรียน:** ธัญรัตน์

## 📌 ส่วนประกอบของเว็บไซต์
1. **หน้าแรก (Home)** แสดงชื่อและข้อมูลเบื้องต้นของเว็บไซต์
2. **แนะนำตัว (About Me)** แสดงข้อมูลส่วนตัวและประวัติของผู้จัดทำ
3. **ผลงาน (Portfolio)** รวบรวมผลงานและโครงงานที่เคยทำ
4. **กิจกรรม (Activities)** แสดงกิจกรรมและประสบการณ์ที่เข้าร่วม

## 🛠️ เครื่องมือที่ใช้
- HTML ใช้สร้างโครงสร้างเว็บไซต์
- CSS ใช้ตกแต่งและจัดรูปแบบเว็บไซต์
- JavaScript ใช้เพิ่มการทำงานของเมนูและส่วนต่าง ๆ
- GitHub ใช้จัดเก็บและเผยแพร่เว็บไซต์
- GitHub Pages ใช้เผยแพร่เว็บไซต์ออนไลน์
